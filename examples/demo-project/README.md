# Demo content workspace

This sample demonstrates the portable project format, an authored prompt, an imported template, and a workflow draft. Open it with a text editor or an Obsidian vault. The `.promptworkspace` index is derived and is intentionally absent from the sample.

To exercise the product path, paste or import the text below into the app:

```text
Write a product description for [PRODUCT] targeting [AUDIENCE] in [LANGUAGE]. Keep it concise and end with three benefits.
```

The app should detect the candidate variables, suggest a template, preserve the raw capture, and write a new asset with imported provenance.
